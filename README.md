# LiveTrans TR → AR

تطبيق Android لترجمة الكلام التركي إلى العربية وعرض الترجمة في نافذة عائمة فوق التطبيقات الأخرى.

## تنزيل APK

1. افتح صفحة المستودع: https://github.com/daterhaij41-glitch/LiveTrans-TR-AR
2. افتح تبويب **Actions**.
3. اختر أحدث تشغيل باسم **Build LiveTrans TR-AR APK**.
4. انتظر حتى تصبح النتيجة خضراء **Success**.
5. افتح التشغيل، ثم انزل إلى قسم **Artifacts**.
6. نزّل **LiveTrans-TR-AR-APK**، وافتح ملف ZIP الناتج.
7. ثبّت `app-debug.apk` على هاتف Android. قد يطلب Android السماح بالتثبيت من مصدر المتصفح أو مدير الملفات.

## إعادة البناء

يبدأ البناء تلقائياً عند كل تحديث لفرع `main`. ويمكن أيضاً فتح Actions، واختيار **Build LiveTrans TR-AR APK**، ثم **Run workflow**.

## ملاحظات مهمة

- هذا الإصدار ينتج APK تجريبياً قابلاً للتثبيت وموقّعاً بشهادة Android debug. ليس إصدار Google Play موقّعاً بمفتاح نشر خاص.
- يلزم Android 10 (API 29) أو أحدث لالتقاط الصوت الداخلي.
- يجب السماح بالظهور فوق التطبيقات، ثم الموافقة على نافذة تسجيل/مشاركة الشاشة من Android.
- بعض التطبيقات تحظر التقاط صوت التشغيل، خاصة المحتوى المحمي. في هذه الحالة قد لا يصل صوت إلى التطبيق.
- نموذج Whisper المحلي يحتاج إلى تنزيله أول مرة، والترجمة المحلية تحتاج إلى تنزيل نموذج ML Kit. بعد ذلك يعمل المسار المحلي دون إنترنت.
- خدمات السحابة اختيارية، وتحتاج إلى مفاتيح API يضيفها المستخدم من الإعدادات. لا تضع مفاتيح API في ملفات المستودع.
- ميزات الأداء والدقة والحرارة يجب قياسها على الهاتف المستهدف؛ نجاح البناء لا يعني ضمان زمن ترجمة أو دقة محددين.
